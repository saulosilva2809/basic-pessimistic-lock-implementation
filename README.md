# Java Concurrency — Pessimistic Locking

Projeto básico desenvolvido em Java com o objetivo de estudar **concorrência, controle de acesso a recursos compartilhados e Lock pessimista**.
## Objetivo

Simular um cenário de compras simultâneas em um sistema de estoque, onde múltiplas threads tentam comprar unidades de um mesmo produto ao mesmo tempo.

O principal objetivo é garantir que duas ou mais threads não modifiquem o estoque simultaneamente, evitando condições de corrida (*Race Conditions*) e inconsistências nos dados.

**Projeto desenvolvido para fins de estudo**, explorando mecanismos de sincronização e proteção de recursos compartilhados em aplicações Java.
